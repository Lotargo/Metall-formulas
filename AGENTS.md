# Metall Formulas

Перед изменением прочитать README.md. Это самостоятельное учебное пособие, а не расчётный backend Metall.

- Сохранять математические выражения, единицы, условия, происхождение, UNKNOWN и реальные границы применимости. Исходные состояния не менять ради оформления.
- Для формул использовать `formulas.json`; для подписей состояний и пояснений — `statuses.py`.
- Калькуляторы оставлять видимыми. Использовать понятные объёмные шильдики с пояснениями при наведении, фокусе и нажатии.
- В HTML не добавлять ссылки на файлы, локальные пути, номера строк и абзацев, отдельный реестр источников и статус «Офлайн · дата». Источники обозначать содержательными именами, функциями, ID формул и разделами документов.
- Сохранять стиль Metall, доступность клавиатуры, мобильное меню и уменьшенное движение. Не загружать зависимости через CDN: готовый HTML должен работать самостоятельно.
- Сборка: `python -X utf8 build.py`. Проверки: `python -X utf8 verify.py`, `node check_learning.mjs`, `npm test`.
- Не коммитить `.audit/`, `.test-results/`, окружения, node_modules и секреты. Полные первоначальные материалы исследования сохраняются локально.
- Коммит, push и публикация выполняются по явному поручению пользователя. Push в `main` запускает GitHub Pages.
- Не добавлять атрибуцию ИИ и Co-Authored-By в коммиты.
