# Metall Formulas

[Открыть справочник](https://lotargo.github.io/Metall-formulas/) · [Репозиторий](https://github.com/Lotargo/Metall-formulas)

Самостоятельное учебное пособие по расчётным формулам Metall: **480 статей, 19 категорий и 60 интерактивных калькуляторов**. Срез исходных материалов: 11.11.2026.

В справочнике собраны геометрия и масса, допуски, заготовки и раскрой, режимы обработки, силы и мощность, время, контроль и смета. Отдельно выделены десять подготовленных методов, прежние реализации и сравнительные исследования.

## Как пользоваться

Откройте сайт или локальный `index.html`. Для чтения достаточно одного HTML: оформление, поиск, калькуляторы и пояснения включены в страницу.

- Ctrl+K переводит фокус в поиск. Фильтр выбирает состояние формулы.
- У каждой формулы показаны обозначения, единицы, условия и происхождение.
- Объёмные шильдики объясняют применение метода при наведении, фокусе или нажатии.
- Калькуляторы постоянно видны. Изменение входов сразу обновляет подстановку и результат; пустые или недопустимые значения дают UNKNOWN.
- На телефоне главы открываются в выдвижном меню. Доступны печать и режим уменьшенного движения.

Источники указаны названиями документов, разделами, именами функций и ID формул. Ссылок на локальные файлы, номеров строк исходников и отдельного реестра источников в пособии нет.

## Локальная сборка

Для сборки нужен Python 3.12 или новее. Пакеты Python и исходный проект Metall не требуются.

```sh
python -X utf8 build.py
python -X utf8 verify.py
python -X utf8 build.py --output dist
```

Первая команда обновляет корневой `index.html`, последняя собирает папку публикации `dist/`.

Для проверки калькуляторов и браузера нужны Node.js 24 или новее и зависимости из lock-файла:

```sh
npm ci
node check_learning.mjs
npx playwright install chromium
npm test
```

На Linux для установки системных зависимостей браузера применяется `npx playwright install --with-deps chromium`. В Windows проверка использует установленный Chrome; альтернативный путь задаётся переменной `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`.

Результаты проверок и скриншоты записываются в `.test-results/`.

## GitHub Pages

Workflow `.github/workflows/pages.yml` запускается при push в `main`, в pull request и вручную. Он собирает страницу, проверяет целостность всех статей, арифметику примеров и поведение в браузере на шести размерах экрана. Публикация выполняется после успешных проверок ветки `main`.

В настройках репозитория **Settings → Pages → Source** выбран **GitHub Actions**. В Pages загружается папка `dist/` с готовым автономным HTML. Конфигурация соответствует [официальной инструкции GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

## Источники и границы

Сохранены **492 указания на 86 источников**, все 138 уникальных ID формул Go и исходные состояния методов. «В рабочем расчёте» означает подключение к расчётному коду в исследованном срезе; результат конкретной детали зависит от входов и применимости метода.

Исследования другой системы, учебные таблицы и нормативные примеры обозначены отдельно. Они не устанавливают авторство формул и не подтверждают их внедрение в Metall. Неподтверждённые значения остаются UNKNOWN. Учебные ставки не становятся коммерческими, а локальные примеры не заменяют производственную проверку.

Первичная инвентаризация охватила 640 файлов кода, 2492 текстовых документа, 529 формульных ячеек XLSX, шесть документов Word и доступный текст 52 PDF. Полный аппарат книг, сканы без читаемого текста, зависимости, бинарные сборки, базы и история Git не объявлены исчерпывающе разобранными.

Полные исходные выгрузки, первоначальные инструменты исследования и протоколы сохранены в локальном архиве `.audit/original/`. Сборка сайта использует редакционный каталог этого репозитория. Исходники продуктового проекта и приватные аудиторские выгрузки для неё не требуются.

Изменения формул требуют сверки выражений, единиц, условий и источников. Контрольный снимок обновляется после содержательной проверки. Пересборка оформления сама по себе не подтверждает актуальность алгоритмов изменившегося продукта.
